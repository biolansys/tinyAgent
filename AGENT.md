# AGENT.md

## Project Overview

Create a Python TUI application that displays system information, network information, and top processes using the Rich library for formatting. The application should:

1. Display system information (OS, CPU, memory, disk usage)
2. Display network information (hostname, local IP, public IP)
3. Display top processes by CPU usage
4. Refresh every 2 seconds
5. Have interactive mode with keyboard controls (q to quit, r to refresh)
6. Have fallback mode without keyboard module
7. Include comprehensive unit tests
